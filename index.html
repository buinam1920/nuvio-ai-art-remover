Nuvio AI Art Remover

Unofficial tool · open source

Remove the AI art from your Nuvio collections

Replace AI-generated tile art (the "AI slop") with real movie and show backdrops. Your collections, tiles and catalogs stay exactly as they are. Only the artwork changes.

Self-hosted server

Use this only if you run your own Nuvio server. The address must start with https://.

Your password goes only to api.nuvio.tv.

Privacy, in plain words

  • Everything runs in this browser tab. There is no server behind this page.
  • Your password is sent only to the Nuvio server shown above, and is never saved anywhere.
  • The sign-in token is kept in memory only. Closing or reloading the tab forgets it.
  • No analytics, no cookies, no tracking. Artwork comes from Cinemeta and Metahub, the public catalogs Stremio uses.
  • Before anything changes, a full backup of your collections is downloaded to your device.

This tool is not made or endorsed by Nuvio. It uses the same sync API as the app, which may change without notice.
